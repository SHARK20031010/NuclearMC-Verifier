# 环 0 槽位定义 v2：固定选项表

**AI 面向规格 · 措辞自由，选项固定**

v1 只给了"要问出什么"。这一版把每个槽位的**互斥选项表**定死。

**核心规矩一句话：AI 可以随便组织问法，但选项表必须原样列出——不能改、不能删、不能合并。**

判别力全部在选项表里。措辞只是包装。

---

# 零、AI 的权限边界

## 可以做的

- 在选项表**前面**加一句话，把选项和题目里的东西对上（"你问的是伽马穿 5 cm 铅板，所以……"）
- 给每个选项**配一句白话解释**
- 标"推荐"，但**必须说明推荐理由**
- 根据题目上下文，**调整选项的排列顺序**（把最可能的放前面）

## 不许做的

| 禁止 | 例子 |
|---|---|
| **改选项文字** | "剂量当量（Sv，需辐射权重）" → "剂量当量" |
| **删选项** | 把"有效剂量"那条去掉 |
| **合并选项** | 把"吸收剂量 / 剂量当量 / 有效剂量"合成一个"剂量" |
| **把推荐当默认** | 用户没答就自己填 |

## 有效回答的判定

用户必须**在列出的选项里点一个**，或者明确说"你决定"。

**其他回答都算无效，必须追问到选项级：**

| 用户说 | 判定 | 怎么办 |
|---|---|---|
| "吸收剂量" | ✅ 有效 | 记 **U** |
| "就剂量吧" | ❌ **无效** | "剂量"正是那个歧义词，必须追问 |
| "你看着办" | ✅ 有效 | 记 **A** |
| "我哪知道" | ✅ 有效 | 记 **A**，AI 给建议 + 理由 |
| 没回 | ✅ 有效 | 记 **A（未问）**，并显眼标出 |

## 每个槽位都有"我不知道"出口

用户常常**真的不知道**（这就是这个课题的前提）。所以每张表最后都有：

```
□ 我不知道 / 你决定
```

选它 → 记 **A**，且 AI 必须给出**建议 + 理由**。
**但绝不能标成 U。**

# 一、F1 要哪个物理量

**两半，缺一不算答**：量 + 作用对象。

## 固定选项表 · 第一半（量）

```
□ 剂量类      —— 能量在物质里沉积了多少
□ 通量/计数类 —— 有多少粒子经过 / 有多少次事件
□ 活度类      —— 生成了多少放射性核素
□ 谱/分布类   —— 结果是一条曲线或一张图，不是一个数
□ 其他        —— 请说明
□ 我不知道 / 你决定
```

## 固定选项表 · 第二半（对象）

**这一半不能预定义**——对象随题目变。

**规矩**：AI 必须**把题目里出现的所有"东西"逐个列出来**，让用户指认。

举例：题目是"1 MeV 伽马打 5 cm 铅板，有多少穿过去"
→ AI 必须列出：`□ 铅板 □ 铅板后面 □ 整块空间 □ 其他 □ 我不知道`

题目是"Cs-137 点源照组织等效方块，方块里吸收剂量"
→ AI 必须列出：`□ 整个方块 □ 方块内某个区域 □ 某个深度 □ 其他 □ 我不知道`

**没列全对象 = 这一项没问。**

## 实战对照

| 题 | 这一项的真歧义 |
|---|---|
| T1-1 "有多少穿过去" | **包括散射后穿过去的吗？**（实测代码报了两个数：全能透射 4.450%、未碰撞 2.750%） |
| T4-1 "全能峰效率" | 分母是"射到晶体上的"还是"源发出的"？ |
| T3-3 "剩余剂量率" | 吸收剂量率还是剂量当量率？ |

# 二、F2 精确定义 ★最重要

**按 F1 选的量，取下表里对应那一行，整行原样列出。**

| F1 选了 | 必须原样列出的互斥选项 |
|---|---|
| **剂量类** | `□ 吸收剂量 D`（Gy，纯物理量，每 kg 物质吸收多少焦耳）<br>`□ 剂量当量 H`（Sv，要乘辐射权重 w_R，中子和伽马不一样）<br>`□ 有效剂量 E`（Sv，还要乘组织权重 w_T，各器官不一样） |
| **通量/计数类** | `□ 通量 Φ`（径迹长度除以体积，或穿过数除以面积）<br>`□ 面通量`（带 1/cosθ 加权，斜穿要算得更多）<br>`□ 体通量`（不带角度加权）<br>`□ 粒子数/计数`（不归一，就是数了几个） |
| **活度类** | `□ 生成的核素原子数`（个）<br>`□ 活度 A`（Bq，每秒衰变多少次）<br>`□ 比活度`（Bq/g 或 Bq/cm³） |
| **谱/分布类** | `□ 微分谱 dN/dE`（每单位能量有多少）<br>`□ 积分谱 N(>E)`（大于某能量的一共多少）<br>`□ 是否按面积/时间归一` |
| **效率**（若题目问效率） | `□ 本征效率`（分母＝射到探测器上的粒子数）<br>`□ 绝对效率`（分母＝源发出的粒子数） |
| **微剂量学类** | `□ 线能 y`（单次事件，keV/µm）<br>`□ 比能 z`（单位质量的累积，Gy）<br>`□ 剂量平均线能 y_D`（按剂量加权的平均） |

```
□ 我不知道 / 你决定
```

## 为什么这项最重要

**数字算对了，但量的身份错了 → 整个答案是错的，而下游每一环都是对的。** 没有任何检查能发现。

而且这项**正是"缺核物理知识"体现得最直接的地方**——用户不知道 `Gy` 和 `Sv` 不是一回事，就不会觉得这里有问题。

# 三、F3 单位

**按 F2 选的，列出合法与非法单位。**

| F2 选了 | 合法 | ⚠️ 必须显式告诉用户 |
|---|---|---|
| 吸收剂量 | Gy / rad / MeV·g⁻¹ | — |
| **剂量当量 / 有效剂量** | Sv / mSv / µSv | **Geant4 里只有 gray，没有 sievert。要 Sv 必须自己补辐射权重/组织权重，程序不提供。** |
| 活度 | Bq / Ci | — |
| 比活度 | Bq/g / Bq/cm³ | — |
| 通量 | cm⁻² / cm⁻²·s⁻¹ | — |

```
□ 我不知道 / 你决定
```

**规矩**：选了需要程序不提供的单位的，AI **必须把上面那句警告说出来**。这不是闲聊，这是这一环唯一的"教"的机会。

# 四、F4 在哪儿算

```
□ 某一点的值          —— 请给坐标
□ 某个体积内的平均值   —— 请给体积
□ 某个面上的平均值     —— 请给面
□ 整个区域的峰值
□ 随空间变化的分布     —— 请给网格
□ 我不知道 / 你决定
```

**⚠️ 选了"某一点的值"，必须告诉用户**：Geant4 核心打分体系**没有点值估计器**，网格量天生是体平均。要真正的点值必须自己改估计量。

---

# 五、F5 什么时候算

```
□ 稳态（长时间平均）
□ 某个时刻的瞬时值     —— 请给时刻
□ 一段时间内的累积     —— 请给时间窗
□ 脉冲                 —— 请给脉冲宽度、重复频率
□ 冷却一段时间之后     —— 请给冷却时间
□ 我不知道 / 你决定
```

**⚠️ 选脉冲、或题目涉及放射性衰变，必须告诉用户**：

- Geant4 里与时间有关的只有 `/gps/time` **一个常数**，**没有脉冲宽度、没有重频**
- 衰变有硬阈值：`G4RadioactiveDecay.cc:114` 的 `fThresholdForVeryLongDecayTime(1.0*CLHEP::year)` —— **寿命超过 1 年的核直接不受理**。Co-60 半衰期 5.27 年就在此列，**默认一个 γ 都不发，且不报错**（实测 500 事件 allGammaSteps=0、exit 0 无 warning）

# 六、F6 归一化基准

```
□ 每个源粒子 / 每个事件   —— 结果只对"一个粒子"而言
□ 每秒                    —— 需要 F9 的源强
□ 每单位活度（Bq）        —— 需要 F9
□ 每单位束流              —— 需要 F9
□ 每单位功率（W）         —— 需要 F9
□ 每次脉冲                —— 需要 F9
□ 我不知道 / 你决定
```

**⚠️ 必须告诉用户**：Geant4 **没有源强、束流、功率这些概念**，一切结果天然是"每源粒子/每事件"。选了后面几项，**这个数不能直接拿去跟别人比，得再乘源强**。

## 特别提醒（针对默认选项）

**"每源粒子"太好选了**——用户很容易一直选它，然后所有结果都不能跟别人比，而他自己不知道。

**规矩**：用户选这项时，AI 必须补一句：

> 这个结果是"每个源粒子贡献多少"。要变成实际的值（比如 µGy/h），还得知道你源有多强。你如果现在不知道，可以先要这个，后面再换算。

---

# 七、F7 允许多大误差

**不给数字选项，给"用途"选项**——因为用户往往真的不知道"1% 是多少"。

```
□ 只是看个大概趋势        —— 相对误差 10–30% 都能接受
□ 要一个能写进报告的数值   —— 1–10%
□ 要跟实验或别的程序定量对比 —— 小于 1%
□ 我不知道 / 你决定
```

**⚠️ 选了最后两项，必须告诉用户**：Geant4 框架**不算也不输出统计误差**（`G4StatDouble::rms()` 有实现但**全树零调用**，`/score/` 只 dump 三个裸量）。

而且有个坑要一起说：**`entry` 列是"命中步数"，不是"跑了多少事件"**（实测某题 DD entries=2406 而实际 5000 事件）。拿它当采样数代进 √N，会**严重高估精度**。

---

# 八、F8 拿什么当判据

```
□ 有实验数据可以对比      —— 请给出处
□ 有解析解或者手册值      —— 请给出处
□ 跟另一个蒙卡程序的结果比 —— 哪个程序？
□ 只要量级对、趋势对就行
□ 说不清 / 没有
□ 我不知道 / 你决定
```

**"说不清"是合法答案**，但必须记下来——因为它意味着**这个结果没有任何独立验证**，这一点应该写进最终交付里。

---

# 九、F9 源的绝对强度 ★条件项

**只有 F6 选了「每秒 / 每 Bq / 每束流 / 每功率 / 每脉冲」时才问。**

**按 F6 的选择，问对应的量：**

```
F6 选了「每秒」    → □ 每秒发出多少粒子  □ 源活度多少 Bq  □ 束流多少
F6 选了「每 Bq」   → 源活度是多少 Bq
F6 选了「每功率」  → 功率是多少 W
F6 选了「每次脉冲」→ 每个脉冲多少粒子
```

**⚠️ 必须告诉用户**：Geant4 里 `/gps/source/intensity` **只是多个源之间的相对比例**，不是绝对强度。程序里没有"源有多强"这个槽位。

## 为什么这条特别要紧

实测 T3-1 就是栽在这——用户没说源强，AI 自己算了一个绝对值，**错 1222 万倍**（多除了一个 λ、少乘了束流面积）。而形状完全正确，所以曲线看起来没问题。

# 十、F10 输出形式

```
□ 一个标量数字
□ 随某个变量变化   —— 深度？时间？角度？能量？位置？
□ 二维 / 三维分布图
□ 能谱（按能量分箱）
□ 我不知道 / 你决定
```

**⚠️ 选了"能谱"，必须告诉用户**：Geant4 计分框架**只支持空间分 bin，不支持能量分 bin**。要能谱得自己写。

# 十一、回执格式（机器可查）

AI 做完环 0 确认，必须产出这张表。**没有回执 = 没问。**

```
F1  量    ：<选项原文>            | 对象：<选项原文>   | 来源：U/A
F2  定义  ：<选项原文>                                | 来源：U/A
F3  单位  ：<选项原文>                                | 来源：U/A
F4  位置  ：<选项原文>            | 补充：<坐标/体积> | 来源：U/A
F5  时间  ：<选项原文>            | 补充：<时间条件>  | 来源：U/A
F6  归一  ：<选项原文>                                | 来源：U/A
F7  误差  ：<选项原文>                                | 来源：U/A
F8  判据  ：<选项原文>            | 出处：<...>       | 来源：U/A
F9  源强  ：<数值+单位> 或 N/A（F6 选了相对基准）      | 来源：U/A
F10 输出  ：<选项原文>                                | 来源：U/A
```

**三条规矩**：
1. 填的是**选项原文**，不是 AI 自己的复述
2. **标了 A 的项，要往下游传标记**
3. **标了「未问」的项，单独列在最前面**

# 十二、哪些槽位被问到会"教"到用户

这是副产品，但对这个课题很重要——**环 0 的确认本身就是一次知识传递**。

| 槽位 | 用户会第一次知道 |
|---|---|
| F2 | Gy 和 Sv 不是一回事；本征效率和绝对效率是两个数 |
| F3 | 程序里只有 gray，没有 sievert |
| F5 | 寿命超过 1 年的核，程序默认根本不衰变 |
| F6 | "每源粒子"这个数不能直接跟别人比 |
| F7 | 原来"误差"是要自己定的；`entry` 不是事件数 |
| F9 | 程序里没有"源有多强"这个输入口 |
| F10 | 计分框架不支持能量分 bin |

**七处。这七处正好是最初那个 idea 的内核**——用户因为不知道这些，问出的问题自己以为很明确，实际有歧义；AI 也不知道他不知道，所以不问。

# 遗留

1. **F1 的"对象"那一半还是没法定死**，只能靠 AI 把题目里的东西列全。"列全"这件事本身没法机械校验——只能靠回执看它列了几项。
2. **选项数量要不要压。** F2 那行有 4 个选项，F6 有 7 个。选项太多用户会乱选。要不要按题目上下文**只列相关的 2–3 个**？但那样又回到"AI 判断哪些相关"了。
3. **F7/F8 的"用途导向"选项还没验过**。用户能不能答上来"这个数是拿去写报告还是跟实验比"，没试过。
4. **回执里的"选项原文"谁来核。** 如果 AI 自己填回执，它能填假的。要不要让插件从 AI 的输出里**机械抽取**选项原文来对？
