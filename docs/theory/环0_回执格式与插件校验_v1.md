# 环 0 回执：AI 输出格式 + 插件机械校验

**v1**

分工：

| 谁 | 干什么 |
|---|---|
| **AI** | 自己组织问法（措辞自由），但**答案必须落进固定枚举** |
| **插件** | 从 AI 的输出里**机械抽取**这个块，逐项对表。**不含 LLM** |

**回执造假不了**——它只能填表里有的值。填了表外的值，插件直接判非法。

**没有这个块 = 没问。**

---

# 一、AI 必须输出的块

AI 在做完环 0 确认后，**必须原样复制这个骨架并填值**：

````
```guardrail-intent
{
  "F1a": {"v": "<量>",       "src": "<U|A>"},
  "F1b": {"v": "<作用对象>",  "src": "<U|A>"},
  "F2":  {"v": "<定义>",     "src": "<U|A>"},
  "F3":  {"v": "<单位>",     "src": "<U|A>"},
  "F4":  {"v": "<位置>",     "src": "<U|A>", "note": "<补充，可省>"},
  "F5":  {"v": "<时间>",     "src": "<U|A>", "note": "<补充，可省>"},
  "F6":  {"v": "<归一>",     "src": "<U|A>"},
  "F7":  {"v": "<误差>",     "src": "<U|A>"},
  "F8":  {"v": "<判据>",     "src": "<U|A>", "note": "<出处，可省>"},
  "F9":  {"v": "<数值+单位 | N/A>", "src": "<U|A>"},
  "F10": {"v": "<输出>",     "src": "<U|A>"},
  "warnings": ["<警告ID>", "..."]
}
```
````

**为什么要用英文短码而不是中文原文**：中文原文会被 AI 顺手改写（"剂量当量"→"剂量当量 H"→"当量剂量"），插件就没法匹配了。**短码是唯一稳定的东西。**

用户看到的仍然是中文选项（措辞那层是自由的），AI 负责把用户的选择**翻译成短码**。

# 二、合法取值总表

## F1a 要哪个物理量

```
dose | fluence | activity | spectrum | efficiency | microdosimetry | other
```

## F1b 作用对象

**自由文本，但必须非空、且不能是"整个"这种没信息的话。**
（这一项没法枚举——对象随题目变。规矩：AI 必须把题目里出现的候选对象逐个列给用户，回执里写用户指认的那个。）

## F2 精确定义（★ 取值取决于 F1a）

| F1a | 合法 F2 取值 |
|---|---|
| `dose` | `absorbed` \| `equivalent` \| `effective` |
| `fluence` | `fluence_vol` \| `fluence_flat` \| `count` |
| `activity` | `atoms` \| `activity` \| `specific` |
| `spectrum` | `diff` \| `integral` |
| `efficiency` | `intrinsic` \| `absolute` |
| `microdosimetry` | `y` \| `z` \| `y_d` |
| `other` | 自由 |

## F3 单位

```
Gy | rad | MeV/g | Sv | mSv | uSv | Bq | Ci | Bq/g | Bq/cm3 | cm-2 | cm-2s-1 | other
```

## F4 在哪儿算

```
point | volume_avg | surface_avg | peak | distribution
```

## F5 什么时候算

```
steady | instant | window | pulse | cooling
```

## F6 归一化基准

```
per_source | per_second | per_bq | per_current | per_power | per_pulse
```

## F7 允许多大误差

```
trend | report | compare
```

## F8 判据

```
experiment | analytic | other_mc | order_only | none
```

## F9 源绝对强度

`"N/A"` 或者 `数值+单位`（正则 `^\s*[\d.eE+-]+\s*[A-Za-z0-9/^-]+\s*$`）

## F10 输出形式

```
scalar | curve | map | spectrum
```

## src 来源

```
U  用户自己说清了
A  用户交给你决定 / 用户不知道 / AI 自己填了
```

**注意：没有"未问"这个取值。** 因为如果 AI 没问，它就不该产出这个块——**没有块本身就是"没问"的信号**，插件会单独报。

## warnings 警告 ID

```
no_sievert                 程序里只有 gray，没有 sievert
no_point_estimator         没有点值估计器
no_pulse                   没有脉冲宽度/重频
long_lived_nuclide         寿命超 1 年的核默认不衰变
no_energy_binning          计分框架不支持能量分 bin
entry_not_events           entry 是命中步数不是事件数
per_source_needs_strength  "每源粒子"要换算需源强
```

# 三、插件的 7 类校验

| # | 校验 | 判据 | 不过怎么办 |
|---|---|---|---|
| 1 | **块存在吗** | 能不能抽出 `guardrail-intent` | 报「**环 0 未确认**」，全项按 A 处理 |
| 2 | **字段齐吗** | 11 个字段 + warnings 全在 | 点名缺哪个 |
| 3 | **取值合法吗** | 每个 `v` 在该槽位的枚举里 | 点名非法值 |
| 4 | **F2 与 F1a 配套吗** | F2 在 F1a 对应的子表里 | 报「定义与量不匹配」 |
| 5 | **F9 条件对吗** | F6=`per_source` → F9 必须 `N/A`；否则 F9 必须有值 | 报「归一基准要源强，但源强没给」 |
| 6 | **该发的警告发了吗** | 按下面这张表逐条对 | 点名漏了哪条警告 |
| 7 | **src 合法吗** | 只能是 U 或 A | 报错 |

## 第 6 类的触发规则（哪些警告是强制的）

| 条件 | 必须包含 |
|---|---|
| F2 ∈ {equivalent, effective} 或 F3 ∈ {Sv, mSv, uSv} | `no_sievert` |
| F4 = `point` | `no_point_estimator` |
| F5 = `pulse` | `no_pulse` |
| F10 = `spectrum` | `no_energy_binning` |
| F7 ∈ {report, compare} | `entry_not_events` |
| F6 = `per_source` | `per_source_needs_strength` |

**为什么警告也要机械核**：这是"必须说出来的实话"。如果只靠 AI 自觉，它会忘。**忘了就等于用户没被告知。**

# 四、顺带产出的一个数字

回执里的 **A 占比**本身就是一个可报的量：

```
环 0 十项里，用户自己定的 X 项，AI 自主定的 Y 项
```

**这正好是最初那个问题的直接答案**——「用户无法审计 Agent 在各层的自主物理决策」。
环 0 是后果最严重的一环，A 占比就是**在这一环上 AI 自主定目标的比例**。

而且它是**机械算出来的**，不用人来判（确定性：prompt 里说没说 → U；AI 填了 → A）。

# 遗留

1. **F1b 没法机械核**。它必须是非空自由文本，但"列全了候选对象没有"插件看不出来。只能靠回执里它写没写东西。
2. **"AI 是不是真的问了"插件还是不知道**。它能知道"AI 声称用户说了 U"，但没法验证用户真说过。除非**把 AI 和用户的对话原文也交给插件**——那就要 CLAUDE 记对话，成本高。现在是靠 src 标签自报。
3. **短码和中文选项谁负责映射**。现在是 AI 负责翻译。如果它翻错（用户选了 Sv，它填 Gy），插件不会发现。可以加一层：**让 AI 同时也回填用户的原话**，插件做关键词粗查。没做。
4. **块的位置要不要强制**。如果 AI 把它写在回答中间，抽取可能被别的 ``` 干扰。倾向要求它写在**回答最前面**，没定。
