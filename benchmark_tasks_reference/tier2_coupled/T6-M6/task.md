# 任务 T6-M6 (Tier 2 中等复杂度 · T6 束流输运与复杂源项)

## 需求描述：
在地面上方设置平面积分源。缪子天顶角严格按照 cos^2(theta) 概率分布抽样，发射到地表倾斜 45 度的地下通道，统计通道内探测器的角响应通量。

## 核心物理观测量：
- **目标观测量**：海平面宇宙射线缪子天顶角 cos^2(theta) 分布与地面倾斜透射


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议控制在 200~350 行以内，结构严谨，具备完整的物理逻辑与数值计分。
