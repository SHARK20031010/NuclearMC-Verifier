# 任务 T6-M1 (Tier 2 中等复杂度 · T6 束流输运与复杂源项)

## 需求描述：
放疗机架围绕等中心以半径 1 米做 360 度圆周旋转。源位置在圆周上均匀抽样，粒子发射动量向量实时计算并指向几何中心原点，验证水箱中心的对称剂量聚焦。

## 核心物理观测量：
- **目标观测量**：旋转照射等中心源空间位置圆周旋转与动量指向中心对准


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议控制在 200~350 行以内，结构严谨，具备完整的物理逻辑与数值计分。
