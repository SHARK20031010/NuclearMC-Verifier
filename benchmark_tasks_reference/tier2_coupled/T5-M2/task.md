# 任务 T5-M2 (Tier 2 中等复杂度 · T5 微剂量与化学)

## 需求描述：
50 nm 金纳米颗粒浸在水中，受到 50 keV X 射线照射。在颗粒表面水界面 100 nm 薄层内挂载 G4StepLimiter 限制最大步长为 10 nm，评估俄歇电子引起的局部剂量增强比 DEF。

## 核心物理观测量：
- **目标观测量**：金纳米颗粒界面微步长限制与低能 Auger 电子剂量增强 (DEF)


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议控制在 200~350 行以内，结构严谨，具备完整的物理逻辑与数值计分。
