# 任务 T4-M3 (Tier 2 中等复杂度 · T4 探测器与符合)

## 需求描述：
BC-501A 液体闪烁体探测 14 MeV 快中子，快中子弹性散射产生高 LET 反冲质子。配置 Birks 常数（0.126 mm/MeV），模拟发光猝灭效应并输出非线性光输出能谱（MeVee）。

## 核心物理观测量：
- **目标观测量**：闪烁体高发光猝灭与重粒子反冲 Birks 常数修正响应


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议控制在 200~350 行以内，结构严谨，具备完整的物理逻辑与数值计分。
