# 任务 T5-M7 (Tier 2 中等复杂度 · T5 微剂量与化学)

## 需求描述：
在微孔道中加入甲酸或 DMSO 自由基清除剂。通过在辐射化学模块中设定清除反应率常数，计算清除剂浓度对羟基自由基在纳秒级扩散距离的抑制比。

## 核心物理观测量：
- **目标观测量**：质子束轰击下超微孔道内自由基清除剂 (Scavenger) 猝灭效应


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议控制在 200~350 行以内，结构严谨，具备完整的物理逻辑与数值计分。
