# 任务 T6-M8 (Tier 2 中等复杂度 · T6 束流输运与复杂源项)

## 需求描述：
由两块极性相反的四极磁铁组成的聚焦-散焦单元（Quadrupole Doublet）。输入具有发散角的电子束，观察束流在 X 和 Y 方向的横向截面收缩聚焦行为。

## 核心物理观测量：
- **目标观测量**：四极聚焦透镜对 (FODO 格子) 带电粒子束横向聚焦与包络振荡


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议控制在 200~350 行以内，结构严谨，具备完整的物理逻辑与数值计分。
