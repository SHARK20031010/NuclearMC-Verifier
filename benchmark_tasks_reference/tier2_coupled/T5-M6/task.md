# 任务 T5-M6 (Tier 2 中等复杂度 · T5 微剂量与化学)

## 需求描述：
细胞核模型为直径 5 微米的球体。在低剂量与高剂量照射下，分别统计单事件比能沉积分布 f1(z) 与包含泊松穿越次数的多事件累积比能分布 f(z; D)。

## 核心物理观测量：
- **目标观测量**：细胞核微球内电离粒子多重穿越的比能 z 单事件与多事件分布


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议控制在 200~350 行以内，结构严谨，具备完整的物理逻辑与数值计分。
