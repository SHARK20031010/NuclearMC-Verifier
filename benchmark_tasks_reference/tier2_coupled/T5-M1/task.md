# 任务 T5-M1 (Tier 2 中等复杂度 · T5 微剂量与化学)

## 需求描述：
直径 1 微米等效的球形组织等效比例计数器（TEPC）受中子照射。利用柯西定理 l_bar = 4r/3 计算单事件微剂量线能 y = edep / l_bar，输出对数分箱的 yd(y) 剂量分布谱。

## 核心物理观测量：
- **目标观测量**：组织等效比例计数器 (TEPC) 微球腔柯西平均弦长 4r/3 线能分布


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议控制在 200~350 行以内，结构严谨，具备完整的物理逻辑与数值计分。
