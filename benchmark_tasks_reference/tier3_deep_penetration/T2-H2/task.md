# 任务 T2-H2 (Tier 3 高等复杂度 · T2 剂量与放疗物理)

## 需求描述：
6 MV 医用加速器束流照射水箱。两组 MLC 叶片（钨合金）按照预设运动轨迹以 2 cm/s 速度相对滑动，形成特定调强照射野。要求在程序中实现时间依赖的叶片动态几何平移或四维相位积分，计算水箱内形成的阶梯形适形剂量场。

## 核心物理观测量：
- **目标观测量**：调强放疗 (IMRT) 动态多叶光栅 (DMLC) 滑窗运动四维剂量积分


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议在 300~600 行以内，结构严谨，具备工业级物理建模、方差缩减权重流维护与复杂计分逻辑。
