# 任务 T1-H8 (Tier 3 高等复杂度 · T1 深穿透与减方差)

## 需求描述：
400 MeV/u 碳离子束偏折打在铜偏转板上。产生的高能中子在 1.5 米厚的含硼混凝土屏蔽墙中减速慢化，并激发 10B(n,alpha)7Li* 产生 478 keV 伽马射线。计算墙内热中子通量峰值深度与墙外次级光子剂量。

## 核心物理观测量：
- **目标观测量**：医用重离子回旋加速器自屏蔽深部中子俘获次级级联射线场


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议在 300~600 行以内，结构严谨，具备工业级物理建模、方差缩减权重流维护与复杂计分逻辑。
