# 任务 T1-H4 (Tier 3 高等复杂度 · T1 深穿透与减方差)

## 需求描述：
千瓦级空间核反应堆发射中子与伽马混合场，距反应堆 20 米处为载人舱。反应堆前端设计 50 cm 厚钨-氢化锂锥形影子屏蔽体。要求在探测器表面对未碰撞弹道粒子与大角度反散射粒子进行独立解耦计分，评估圆锥屏蔽边缘泄漏散射。

## 核心物理观测量：
- **目标观测量**：核动力深空探测器大功率空间堆与载人舱之间影子屏蔽 (Shadow Shield)


### 交付外壳规范：
1. 目标平台 Geant4 11.2.2（本机已装，geant4-config 在 PATH 中）。
2. 单个 .cc 文件，自带 main()，能直接 g++ -O2 编译运行，不依赖外部宏文件或数据文件。
3. 代码规模建议在 300~600 行以内，结构严谨，具备工业级物理建模、方差缩减权重流维护与复杂计分逻辑。
