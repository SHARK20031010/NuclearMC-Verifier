## 现象

`G4HadronElasticPhysicsHP` 的构造过程里，先注册高精度模型，同时把已有的
`hElasticCHIPS` 的能量下限改成 19.5 MeV：

```cpp
he->SetMinEnergy(19.5*CLHEP::MeV);        // ★ 已有模型被改
hel->RegisterMe(new G4ParticleHPElastic()); // ★ 新模型加进来
hel->AddDataSet(new G4ParticleHPElasticData());
```

## 为什么是问题

"HP" 这个名字让人以为只是**多**了一个高精度模型，不会想到它同时**砍掉**了
原模型的适用范围。0–19.5 MeV 这段的物理处理被整体换掉了。

本机实测（FTFP_BERT vs FTFP_BERT_HP）：

```
FTFP_BERT     hElasticCHIPS  Emin = 0 eV
FTFP_BERT_HP  hElasticCHIPS  Emin = 1.95e+07 eV   ← 被改
              NeutronHPElastic  Emin = 0 eV, Emax = 20 MeV  ← 新来的
```

## 不适用的情况

如果你本来就想要 HP 模型，这不是问题 —— 但**你应当知道**原来的模型被改了范围。
