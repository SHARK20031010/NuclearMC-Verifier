# 粒子输运蒙卡程序形式化核验技能 (MC-FormalVerifier Skill)

本技能提供针对粒子输运蒙特卡罗仿真代码的形式化验证与确认（Formal V&V）能力。

## 一、何时调用本技能

- 当用户要求生成 Geant4 C++ 粒子输运代码（或规划 OpenMC/MCNP 模型）时；
- 当需要审查或重构现有辐射探测、屏蔽设计或核动力学仿真程序时；
- 当遇到物理计数失真、吸收剂量数个数量级偏差或深穿透假收敛疑难时。

## 二、执行核验命令

对指定的仿真代码文件运行形式化核验：

```bash
# 基础核验命令
python3 guardrail/check.py --code <代码路径.cc>

# 强制要求输入规约契约并输出 JSON 结构化报告
python3 guardrail/check.py --code <代码路径.cc> --require-intent --json
```

## 三、审查五大物理守恒不变式

核验器在代码静态 AST 层面执行以下刚性物理断言：
1. **能量与动量守恒**：核反应 Q 值、初始动能与沉积/逃逸能量闭环；
2. **守恒荷数**：电荷数、重子数、轻子数在微观相互作用中严格守恒；
3. **相空间与角分布测度**：各向同性立体角测度微元 $d\Omega = \sin\theta d\theta d\phi$（禁止笛卡尔线性替代）；
4. **输运统计无偏性与减方差权重**：重要抽样与俄罗斯轮盘赌必须严格传递 `GetWeight()`；
5. **量纲链与响应标度线性性**：吸收剂量（Gy = J/kg）必须除以真实介质质量，单位链严禁混淆。

## 四、违约反例修复指引

当核验器报告违约槽位（如 `[PHYS-0004]`、`[PHYS-0026]`）时：
- **严禁**：通过硬编码经验常数、伪造分母或修改常数系数迎合数值；
- **正确做法**：回溯输入规约契约，核实几何体积真实质量、相空间立体角抽样数学公式或框架 API 步进后点（`PostStepPoint`）状态，从机理层面消除缺陷。
